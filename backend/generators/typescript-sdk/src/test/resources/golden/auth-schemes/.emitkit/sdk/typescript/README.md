# Auth Schemes

TypeScript client for the Auth Schemes API, generated by Emit-Kit. Files under `src/` other than
`src/custom/` are overwritten on every generation run.

## Install

```sh
npm install @acme/petstore-sdk
```

## Usage

```ts
import { AuthSchemesClient } from "@acme/petstore-sdk";

const client = new AuthSchemesClient({ baseUrl: "https://api.example.com" });
```

Pass `baseUrl` when the API declares no servers. Credentials are set through the `AuthOptions`
fields in `src/client.ts`, one per security scheme the API declares.

## Errors

Non-2xx responses throw an `ApiError` subclass: `BadRequestError` (400), `UnauthorizedError` (401),
`ForbiddenError` (403), `NotFoundError` (404), `ConflictError` (409), `RateLimitError` (429) or
`ServerError` (5xx). Other statuses throw a plain `ApiError`. Each error carries `status`, `body`
and `headers`.

429 and 5xx responses are retried with exponential backoff, twice by default. Set `maxRetries` to
change that.

## Build

```sh
npm install
npm run build
```
