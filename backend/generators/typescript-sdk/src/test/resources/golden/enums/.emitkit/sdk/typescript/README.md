# Enums

TypeScript client for the Enums API, generated by Emit-Kit. Files under `src/` other than
`src/custom/` are overwritten on every generation run.

## Install

```sh
npm install @acme/petstore-sdk
```

## Usage

```ts
import { EnumsClient } from "@acme/petstore-sdk";

const client = new EnumsClient({ baseUrl: "https://api.example.com" });
```

## Base URL

The API declares no absolute server URL. Pass the full base URL, e.g. https://api.example.com.

## Authentication

Credentials are set through the `AuthOptions` fields in `src/client.ts`. Each field exists only when
the API declares a matching scheme: `apiKey` for API key schemes, `bearerToken` for HTTP bearer,
OAuth2 and OpenID Connect schemes, and `basic` for HTTP basic. Other schemes, such as cookie API
keys, are not mapped. Set them with a custom `fetch`.

## Errors

Non-2xx responses throw an `ApiError` subclass: `BadRequestError` (400), `UnauthorizedError` (401),
`ForbiddenError` (403), `NotFoundError` (404), `ConflictError` (409), `RateLimitError` (429) or
`ServerError` (5xx). Other statuses throw a plain `ApiError`. Each error carries `status`, `body`
and `headers`.

429 and 5xx responses are retried with exponential backoff, twice by default. Set `maxRetries` to
change that.

## Build

```sh
npm install
npm run build
```
