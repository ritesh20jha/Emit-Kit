# Petstore

Java client for the Petstore API, generated by Emit-Kit. Files under `src/main/java/` other than
`src/main/java/com/acme/petssdk/custom/` are overwritten on every generation run.

## Install

```kotlin
implementation("com.acme:pets-sdk:1.2.3")
```

## Usage

```java
import com.acme.petssdk.PetstoreClient;

PetstoreClient client = PetstoreClient.builder()
    .baseUrl("https://api.example.com")
    .build();
```

## Base URL

The API declares no absolute server URL. Pass the full base URL, e.g. https://api.example.com.

## Authentication

Credentials are set on the builder. Each method exists only when the API declares a matching
scheme: `apiKey` for API key schemes, `bearerToken` for HTTP bearer, OAuth2 and OpenID Connect
schemes, and `basic` for HTTP basic. Other schemes, such as cookie API keys, are not mapped.

## Errors

Non-2xx responses throw an `ApiException` subclass: `UnauthorizedException` (401 and 403),
`NotFoundException` (404), `ConflictException` (409), `RateLimitException` (429) or
`ServerException` (5xx). Other statuses throw a plain `ApiException`. Each exception carries
`status()` and `body()`. A failed connection throws `UncheckedIOException`.

429 and 5xx responses are retried with exponential backoff, twice by default. Set `maxRetries` on
the builder to change that.

## Build

```sh
gradle build
```
