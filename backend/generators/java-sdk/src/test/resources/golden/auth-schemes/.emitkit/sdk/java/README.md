# Auth Schemes

Java client for the Auth Schemes API, generated by Emit-Kit. Files under `src/main/java/` other than
`src/main/java/com/acme/petssdk/custom/` are overwritten on every generation run.

## Install

```kotlin
implementation("com.acme:pets-sdk:1.2.3")
```

## Usage

```java
import com.acme.petssdk.AuthSchemesClient;

AuthSchemesClient client = AuthSchemesClient.builder()
    .baseUrl("https://api.example.com")
    .build();
```

## Base URL

The API declares no absolute server URL. Pass the full base URL, e.g. https://api.example.com.

## Authentication

Credentials are set on the builder. Each method exists only when the API declares a matching
scheme: `apiKey` for API key schemes, `bearerToken` for HTTP bearer, OAuth2 and OpenID Connect
schemes, and `basic` for HTTP basic. Other schemes, such as cookie API keys, are not mapped.

## Errors

Non-2xx responses throw an `ApiException` subclass chosen by status: `UnauthorizedException` (401
and 403), `NotFoundException` (404), `ConflictException` (409), `RateLimitException` (429) or
`ServerException` (5xx). Other statuses throw a plain `ApiException`. A failed connection throws
`UncheckedIOException`. 429 and 5xx responses are retried twice by default, and requests time out
after 60 seconds. Set `maxRetries` or `timeout` on the builder to change these.
