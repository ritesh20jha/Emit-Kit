# Petstore

Python client for the Petstore API, generated by Emit-Kit. Files under `acme_pets/` other than
`acme_pets/custom/` are overwritten on every generation run.

## Install

```sh
pip install acme-pets
```

## Usage

```python
from acme_pets import PetstoreClient

client = PetstoreClient(base_url="https://api.example.com")
```

Use a client as a context manager to close its HTTP connections on exit:

```python
with PetstoreClient(base_url="https://api.example.com") as client:
    ...
```

The async client, `AsyncPetstoreClient`, is used the same way with `async with`:

```python
async with AsyncPetstoreClient(base_url="https://api.example.com") as client:
    ...
```

## Base URL

The API declares no absolute server URL. Pass the full base URL, e.g. https://api.example.com.

## Authentication

Credentials are keyword arguments to the client constructor. Each argument exists only when the API
declares a matching scheme: `api_key` for API key schemes, `bearer_token` for HTTP bearer, OAuth2 and
OpenID Connect schemes, and `basic` for HTTP basic, as a `(username, password)` tuple. Other schemes,
such as cookie API keys, are not mapped. Set them on a custom `http_client`: an `httpx.Client`, or an
`httpx.AsyncClient` for the async client.

Header and cookie parameters of an operation are not method arguments yet, so they are not sent. Set
them on a custom `http_client`, for example `httpx.Client(headers={"X-Tenant": "acme"})`.

## Errors

Non-2xx responses raise an `ApiError` subclass: `BadRequestError` (400), `UnauthorizedError` (401),
`ForbiddenError` (403), `NotFoundError` (404), `ConflictError` (409), `RateLimitError` (429) or
`ServerError` (5xx). Other statuses raise a plain `ApiError`. Each error carries `status`, `body`
and `headers`.

429 and 5xx responses are retried with exponential backoff, twice by default. Set `max_retries` to
change that.
