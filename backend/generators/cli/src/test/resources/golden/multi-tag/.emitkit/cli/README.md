# Multi Tag CLI

Command-line client for the Multi Tag API, generated by Emit-Kit. Every file in this package is
overwritten on each generation run.

## Install

```sh
npm install -g @acme/petstore-cli
```

## Usage

```sh
petstore <group> <operation> [options]
```

Global options, accepted before or after the command: `--base-url <url>`, `--token <token>` (sent
as a bearer token), `--api-key <key>` (sent in the header, query parameter or cookie the API
declares), and `--output json|table` (default `json`). A credential is sent only to operations whose
security requirement declares it. When an operation lists alternative security requirements,
every configured credential named by any of the operation's alternative security requirements is sent, with at most one API key per request. Request bodies use `--json <body|@file>`.

## Base URL

The API declares no absolute server URL, so pass `--base-url`, for example `--base-url https://api.example.com`.

## Commands

- `petstore pets get-pet-inventory`
- `petstore admin reset-pets`
- `petstore store list-store-orders`
