# Polymorphism

MCP server for the Polymorphism API, generated by Emit-Kit. Each API operation is one tool. The server
speaks MCP over stdio and calls the API over HTTP.

## Build

```sh
npm install
npm run build
```

## Run

```sh
API_BASE_URL=https://api.example.com node dist/server.js
```

Point an MCP client at `node /absolute/path/to/dist/server.js`, with the same environment variables
set in the client's server configuration.

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `API_BASE_URL` | yes | Base URL that each tool's path is appended to, for example `https://api.example.com/v1`. A trailing slash is removed. |
| `API_TOKEN` | no | Sent as `Authorization: Bearer <token>` on the tools whose operation accepts a bearer or OAuth2 token. |
| `API_KEY` | no | Sent in the header, query parameter or cookie the spec declares, on the tools whose operation accepts that API key. |

A tool sends a credential only when its operation's security requirement lists the scheme, so an
operation that declares `security: []` gets no credentials. When an operation lists alternative
security requirements, one of them is sent: the first whose credentials are all configured,
preferring one that does not put an API key in the URL. A request carries at most one API key.

Request bodies are sent as JSON. The tools are listed in `src/tools.ts`.
