# Petstore

MCP server for the Petstore API, generated by Emit-Kit. Each API operation is one tool. The server
speaks MCP over stdio and calls the API over HTTP.

## Build

```sh
npm install
npm run build
```

## Run

```sh
API_BASE_URL=https://api.example.com node dist/server.js
```

Point an MCP client at `node /absolute/path/to/dist/server.js`, with the same environment variables
set in the client's server configuration.

## Configuration

| Variable | Required | Purpose |
| --- | --- | --- |
| `API_BASE_URL` | yes | Base URL that each tool's path is appended to, for example `https://api.example.com/v1`. A trailing slash is removed. |
| `API_TOKEN` | no | Sent as `Authorization: Bearer <token>` on every request. |
| `API_KEY` | no | Sent in the API key header or query parameter the spec declares. Unused when the spec declares none. |

Request bodies are sent as JSON. The tools are listed in `src/tools.ts`.
